# Security

Do not report a suspected vulnerability in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/connorlhunter/cipher-wallet/security/advisories/new). Include the affected version or commit, reproduction steps, expected impact, and any suggested fix. Do not include recovery phrases, private keys, WIF values, wallet backups, credentials, or Testnet funds.

Cipher Wallet is in Testnet MVP development. Only the current main branch is supported, and there is no public bug bounty or guaranteed response time.
